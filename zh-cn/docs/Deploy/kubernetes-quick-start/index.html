Kubernetes 快速开始（kind / minikube）

本指南使用 Helm Chart 在本地 Kubernetes 集群中运行 Curvine，并通过 CSI 驱动把 Curvine 卷挂载到 Pod 中。从一台空机器开始，最终得到一个能向 Curvine 写入文件并读回的 Pod。

本文以 kind 为例，文末附有 minikube 的做法。用到的两个 Helm Chart：

ChartRelease命名空间用途
curvine/curvinecurvinecurvineCurvine master 和 worker
curvine/curvine-csicurvine-csicurvine-system通过 FUSE 将 Curvine 挂载到 Pod 的 CSI 驱动

生产集群部署及完整的 Chart 参数说明，请参考 Kubernetes 部署 和 K8S CSI 驱动。

前置条件

  • Docker，至少可用 2 个 CPU 和 2 GB 内存
  • kind 0.20 或更高版本
  • kubectl
  • Helm 3

本指南已在 kind v0.27.0（Kubernetes v1.32.2）和 minikube v1.25.1（Kubernetes v1.23.1）上验证，Chart 版本为 0.5.2-alpha。

故障排查

现象检查
master 或 worker Pod 处于 Pendingkubectl describe pod -n curvine <pod>。通常是 Docker 内存不足，或没有 standard StorageClass（kubectl get storageclass）。
PVC curvine-test-pvc 一直 Pendingkubectl logs -n curvine-system -l app=curvine-csi-controller -c csi-plugin。确认 kubectl get pods -n curvine 中 master 正在运行。
测试 Pod 卡在 ContainerCreatingkubectl describe pod curvine-test，然后 kubectl logs -n curvine-system -l app=curvine-csi-node -c csi-plugin。节点上缺少 /dev/fuse 时会在这里报错。
