Environment Initialization

This chapter summarizes common Curvine development environment setups. The current main branch is Linux-first; macOS is mainly useful for development and limited local testing. If you work from Windows, use a Linux environment through WSL rather than treating native Windows as the primary build target.

Dependencies

  • GCC: version 10 or later (GCC Installation)
  • Rust: version 1.98 (pinned by rust-toolchain.toml; build/check-env.sh accepts 1.86 or later) (Installation Guide)
  • Protobuf: version 3.x+ (Install Guide)
  • Maven: version 3.8 or later (Install Guide)
  • LLVM: version 12 or later (Installation Guide)
  • FUSE: libfuse2 or libfuse3 development packages
  • JDK: version 1.8 or later (OpenJDK or Oracle JDK)
  • npm: version 9 or later (Node.js Installation)
  • Python: version 3.7 or later

In particular, the protoc compiler version and its supported protocol capabilities reference:
